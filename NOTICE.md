# Scope of the MIT license

`LICENSE` covers the code written by the authors. It deliberately contains nothing
but the MIT text, because GitHub detects licenses by text similarity and any addition
makes it stop recognising the file. The exceptions live here instead.

The MIT license does not cover material in this repository that we did not write and
do not own. Wherever a directory carries its own `LICENSE` or `NOTICE.md`, that file
governs its contents and takes precedence:

| Path | Governed by |
|---|---|
| `web-data-collection-gcs/pages/fake_pages/instagram-clone/` | `LICENSE` — MIT, Leonardo Costa |
| `web-data-collection-gcs/pages/fake_pages/Facebook-Clone/` | `NOTICE.md` — third party, license unknown |
| `web-data-collection-gcs/pages/fake_pages/twitter-clone/` | `NOTICE.md` — third party, unlicensed upstream |
| `web-data-collection-gcs/pages/hosting/videos/` | `NOTICE.md` — copyrighted clips, included as fair use |

We claim copyright only over our own contributions to those directories, and license
those contributions under the MIT terms in `LICENSE`. We grant no rights in the
underlying third-party material, because we hold none to grant.

`datasets/clean-data/` holds human-subjects research data and is likewise not covered
by the MIT license. It is released under CC BY 4.0; its own `LICENSE` states the
terms and how to credit it (by citing the paper).

**If you are a rights holder** and object to anything included here, open an issue and
we will remove it.
